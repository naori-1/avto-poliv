# Схема подключения

Питание всей схемы — от USB через плату ESP32. Пин `VIN` на плате выдаёт 5 В от USB, пин `3V3` — 3,3 В.

## Шины макетной платы
| Шина | Откуда |
|---|---|
| `+5V` (красная, левая сторона) | `VIN` ESP32 |
| `+3V3` (красная, правая сторона) | `3V3` ESP32 |
| `GND` (синие, обе стороны) | `GND` ESP32 |

## Датчик влажности почвы v1.2
| Пин датчика | Куда | Примечание |
|---|---|---|
| VCC | `+3V3` | от 3,3 В выход датчика не превышает 3,3 В — безопасно для АЦП ESP32 |
| GND | `GND` | |
| AOUT | `GPIO34` | вход АЦП1, работает и при включённом Wi-Fi |

## Модуль реле 5V (1 канал)
| Пин реле | Куда |
|---|---|
| VCC (DC+) | `+5V` |
| GND (DC−) | `GND` |
| IN | `GPIO26` |

Модуль срабатывает от низкого уровня (LOW). В коде это задано константой `RELAY_ACTIVE_LOW = true`.

## Мини-помпа 5V через реле
| Откуда | Куда |
|---|---|
| `+5V` | клемма реле `COM` |
| клемма реле `NO` | красный провод помпы (+) |
| чёрный провод помпы (−) | `GND` |

`NO` — нормально разомкнутый контакт: пока реле выключено, помпа обесточена. Если ESP32 перезагрузится, помпа сама не включится.

## Светодиоды
Длинная ножка (анод) — к пину ESP32 через резистор 220 Ом, короткая (катод) — на `GND`.

| Светодиод | Пин ESP32 | Значение |
|---|---|---|
| Красный | `GPIO25` → 220 Ом → LED → `GND` | сухо |
| Синий | `GPIO14` → 220 Ом → LED → `GND` | идёт полив |
| Зелёный | `GPIO27` → 220 Ом → LED → `GND` | норма |

## Итог по пинам ESP32
| Пин | Что подключено |
|---|---|
| `GPIO34` | AOUT датчика влажности |
| `GPIO26` | IN реле |
| `GPIO25` | красный светодиод |
| `GPIO14` | синий светодиод |
| `GPIO27` | зелёный светодиод |
| `VIN` | шина +5V (реле, помпа) |
| `3V3` | шина +3V3 (датчик) |
| `GND` | шины GND |

## Советы по сборке
- Датчик втыкать в почву только до белой линии на плате: электроника сверху не защищена от воды.
- Помпа должна лежать в ёмкости с водой полностью, всухую она быстро портится.
- Конец трубки закрепить у корня растения, а датчик воткнуть на 3–5 см в сторону, чтобы вода доходила до него не сразу, а через почву.
