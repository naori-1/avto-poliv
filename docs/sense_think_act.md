# Sense – Think – Act

```
 SENSE                     THINK (ESP32)                            ACT
┌──────────────┐   АЦП   ┌───────────────────────────────────┐   ┌─────────────────────┐
│ Ёмкостный    │ ──────► │ 1. Скользящее среднее (10 замеров) │──►│ Реле → мини-помпа   │
│ датчик       │ 0..4095 │ 2. Пересчёт в % влажности          │   │                     │
│ влажности    │         │ 3. Пороги 30 % / 60 % (гистерезис) │──►│ Красный LED — сухо  │
│ почвы v1.2   │         │ 4. Автомат: СУХО / ПОЛИВ / ВЛАЖНО  │   │ Синий LED — полив   │
└──────────────┘         └───────────────────────────────────┘   │ Зелёный LED — норма │
                                                                  └─────────────────────┘
```

## Sense — измерение
Ёмкостный датчик v1.2 стоит в горшке и непрерывно измеряет влажность почвы. Он выдаёт аналоговое напряжение: чем суше почва, тем оно выше. ESP32 читает его на `GPIO34` каждые 200 мс и получает число от 0 до 4095.

Ёмкостный датчик выбран вместо резистивного (с двумя оголёнными щупами), потому что у него нет металла в контакте с землёй. Он не окисляется и не портится через пару недель.

## Think — обработка
1. **Скользящее среднее.** Отдельные замеры скачут на ±50–100 единиц из-за шумов АЦП и проводов. Программа хранит последние 10 замеров (2 секунды) и работает с их средним. Так один случайный скачок не включает помпу.
2. **Пересчёт в проценты.** Сырое число переводится в проценты влажности по двум точкам калибровки: датчик на воздухе = 0 %, датчик в воде = 100 %.
3. **Гистерезис.** Порогов два: ниже 30 % почва считается сухой, выше 60 % — влажной. Между ними состояние не меняется. С одним порогом помпа щёлкала бы туда-сюда, пока значение колеблется около границы.
4. **Конечный автомат** из трёх состояний — [рисунок](fsm.png):
   - **ВЛАЖНО** — всё в норме, ждём, пока почва подсохнет.
   - **СУХО** — влажность упала ниже 30 %. Ждём 3 секунды, чтобы убедиться, что это не скачок, и включаем полив.
   - **ПОЛИВ** — помпа работает, пока влажность не поднимется выше 60 %. Если за 15 секунд почва не намокла, помпа выключается, и система ждёт 30 секунд, пока вода впитается, а потом проверяет снова.

## Act — действие
- **Реле** на `GPIO26` замыкает цепь 5 В мини-помпы. Помпа подаёт воду из ёмкости по силиконовой трубке к растению.
- **Светодиоды** показывают текущее состояние автомата: красный — сухо, синий — идёт полив, зелёный — норма.
